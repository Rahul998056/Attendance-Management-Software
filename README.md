📊 Attendance Management Software

A full-stack Attendance Management System designed to manage student attendance efficiently.
This system allows admins to manage students, teachers, classes, and attendance records with proper database structure and authentication.

🚀 Features

👨‍🎓 Add / Update / Delete Students

👨‍🏫 Manage Teachers

🏫 Manage Classes & Subjects

📅 Mark Daily Attendance

📊 View Attendance Reports

🔐 Authentication System (Login / Logout)

🗄️ MySQL Database Integration
